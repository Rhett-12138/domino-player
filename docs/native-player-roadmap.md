# 原生播放器技术路线（Route B）

> 状态：规划中 · 目标：实时模型超分 + 美颜的原生播放器，取代 Electron 方案中对实时模型超分的限制

## 0. 背景与决策

- **现状**：Electron + WebGL2 方案中，实时美颜与基础超分已达标（GPU 着色器）；实时**模型**超分因 IPC 拷贝 + wasm/f16 限制无法达标。
- **本路线**：纯原生播放器（C++），帧全程尽量留在 GPU，模型超分在进程内运行。
- **核心假设（须先验证）**：RTX 级 GPU 上 NCNN Vulkan 进程内推理 + 无跨进程拷贝，可实现 **720p 源 → 1080p 输出 30fps** 的实时模型超分。

## 1. 技术选型

| 组件 | 选型 | 理由 |
|---|---|---|
| 语言 | C++17/20 | 与 NCNN/FFmpeg 生态一致 |
| UI | Qt 6（QML 优先，Widgets 备选） | 开发最快、原生性能好 |
| 解码 | FFmpeg + D3D11VA/NVDEC 硬解 | 帧直接落到 GPU 纹理 |
| 渲染 | D3D11 交换链 + 着色器 | 与 NVDEC/Media Foundation 互操作成熟 |
| 模型超分 | **NCNN Vulkan**（先）/ TensorRT（后） | NCNN 模型现成；TensorRT 可再提速 |
| 人脸检测 | OpenCV DNN（RetinaFace/UltraFace + 106点） | 轻量、文档好、C++ 稳定 |
| 美颜 | HLSL 计算/像素着色器（移植现有 GLSL） | 现有着色器数学可直接复用 |
| 音频 | FFmpeg + WASAPI | 成熟 |
| 离线超分 | 同一推理管线 + NVENC 硬件编码 | 比现 Electron 快一个量级 |
| 构建 | CMake + vcpkg | 依赖管理 |

## 2. 总体架构

```
┌──────────────────────────────────────────────────────┐
│ Qt UI（控制条/面板/预设/快捷键/拖拽）                  │
├──────────────────────────────────────────────────────┤
│            PlayerCore（单线程 + 队列）                 │
│  FFmpeg硬解(NVDEC) → 视频帧纹理(共享GPU)              │
│        ↓                                             │
│  着色器管线(HLSL)：磨皮/美白/塑形/妆容 → 滤镜          │
│        ↓                                             │
│  NCNN Vulkan 超分（进程内，GPU 直接或 CPU Mat）        │
│        ↓                                             │
│  D3D11 交换链渲染（letterbox + vsync）                │
│        ↕                                             │
│  Audio 线程：FFmpeg 解码音频 → WASAPI 播放             │
└──────────────────────────────────────────────────────┘
```

**帧数据流（两条路径）**

- **路径 A（理想，P3 优化）**：NVDEC 解码 → D3D11 纹理 → NCNN `VkImageTensor` 直读 → 结果留 GPU → 显示。零 CPU 拷贝。
- **路径 B（P1 起点，可靠退路）**：解码 → CPU Mat → NCNN 推理（Vulkan 加速）→ CPU 结果 → 上传 GPU 显示。同进程内往返约 5-10ms/帧，对 720p 实时完全可行。

## 3. 分阶段计划

### P1 · 原型验证（1-2 周）—— 先验证核心假设

**交付物**：独立控制台窗口 + D3D11 显示；硬解 720p 视频 → NCNN 实时超分 → 30fps 显示；无 UI。

**任务**
1. [x] CMake + 工程骨架；FFmpeg 解码（BtbN 预编译，软解起步）
2. [x] D3D11 交换链 + 全屏三角形显示纹理
3. [x] NCNN Vulkan 加载 `RealESRGAN_General_x4_v3`
4. [x] 逐帧推理 + 显示（CPU Mat 路径）
5. [x] 帧率打点（多档输入分辨率）

**验收**：✅ **通过** —— 实测结果（RTX 4070 SUPER，720p h264 源）：

| 模型输入 | 输出 | 帧率 |
|---|---|---|
| 270 | 1080p | **~65 fps** |
| 360 | 1440p | **~47 fps** |
| 480 | 1920p | ~29 fps |
| 540 | 2160p | ~23 fps |

核心假设（1080p 输出 ≥30fps）**以 2 倍余量达成**；D3D11 窗口实时显示正常（1080p@62fps），进程退出干净。
构建：仓库根 `CMakeLists.txt`（CMake + MSVC），产物 `build/Release/domino_p1.exe`。

**后续可优化**：硬件解码（D3D11VA/NVDEC）、NCNN `VkImageTensor` GPU 直通（消除 CPU 往返）、TensorRT 提速。

### P2 · 播放器核心（3-5 周）

**交付物**：完整可用的播放器（UI + 音频 + 离线超分）。

**任务**
1. [ ] Qt 窗口/控制条/进度/音量/快捷键/拖拽/多文件
2. [ ] A/V 同步（音频时钟驱动视频帧）
3. [ ] seek/快进快退（硬解 seek 处理）
4. [ ] 字幕（可选，ass/srt）
5. [ ] 离线超分：同一推理管线 + NVENC（h264/hevc）编码输出 mp4；进度/取消
6. [ ] 参数持久化（QSettings）

**验收**：播放流畅（音频同步无漂移）、seek 准确、离线超分能输出可播放 mp4。

### P3 · 美颜移植（2-3 周）

**交付物**：皮肤/塑形/妆容三分类 + 预设，面板 UI。

**任务**
1. [ ] 移植现有着色器（磨皮/美白/瑕疵/塑形/瘦脸含V脸/大眼/口红/腮红）→ HLSL
2. [ ] OpenCV DNN 人脸检测 + 106 点关键点
3. [ ] 关键点时间平滑（One-Euro，移植现有 LandmarkSmoother）
4. [ ] 妆容 mask 生成（Canvas→CPU 绘制，逻辑现成）
5. [ ] 分类开关/预设/置灰交互
6. [ ] （可选）NCNN `VkImageTensor` GPU 直通优化

**验收**：美颜效果与现 Electron 版本一致；实时帧率 ≥ 30fps（叠加超分后）。

### P4 · 打磨与分发（1-2 周）

**任务**
1. [ ] 性能剖析与优化（帧队列/缓冲、降级策略）
2. [ ] 异常/崩溃处理、日志
3. [ ] 兼容性测试（不同显卡/驱动/NVIDIA/AMD/Intel）
4. [ ] 打包（安装包/绿色版）、图标、关于

**验收**：稳定运行、常见 GPU 兼容、可分发给测试用户。

## 5. 风险登记表

| # | 风险 | 等级 | 缓解 |
|---|---|---|---|
| 1 | NCNN VkImageTensor GPU 直通不成熟 | 中 | 先走 CPU Mat 退路（已验证 5-10ms/帧足够） |
| 2 | 人脸检测选型（MediaPipe 重 / OpenCV 轻） | 中 | 选 OpenCV DNN；关键点精度不足再上 MediaPipe |
| 3 | A/V 同步难调 | 中 | 音频时钟驱动；预留 3-5 天调优 |
| 4 | 不同 GPU/驱动兼容 | 中 | NCNN Vulkan 自带降级（CPU fallback）；驱动列表测试 |
