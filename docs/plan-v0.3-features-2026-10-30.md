# V0.3 功能优先计划（2026-10-30 调整）

> 范围调整：**暂停 Windows 安装版/签名/混合显卡性能验证**，只保留绿色 zip；先完成播放器与超分/任务功能，再谈稳定发布。

## 一、当前基础

已完成：

- 实时 SR：1080p/2K/4K、自动降档、低 SR FPS 保持 1x。
- TensorRT 零拷贝 + CPU/NCNN 回退，自动/兼容/性能三档。
- 诊断页：adapter、驱动、backend、cudart/TensorRT/Vulkan、H264 能力、零拷贝/降级原因。
- 4K 零拷贝 1 小时长稳（60.1 分钟、5 次 seek，资源无持续增长）。
- 任务中心：创建/启动/停止/续编/删除/边播按钮；模型/质量档持久化。
- 绿色 zip 已能完整运行（当前 beta 已验证安装/解压形态）。

## 二、V0.3 功能清单

### P0：先补齐“播放器日常可用”

1. **绿色包自包含**
   - zip 解压即可运行，不依赖安装器。
   - 评估随包 VC++ Runtime（`msvcp140/vcruntime140/vcruntime140_1`），避免用户先装运行库。
   - 去掉发布流程中的安装器步骤；保留脚本但默认只出 zip。
   - 从任意目录启动、路径带空格/中文、无仓库依赖。

2. **音轨/字幕**
   - 列出音轨、切换音轨。
   - 字幕：内嵌字幕轨/外挂字幕基础支持、开关/选择。
   - 默认音轨/字幕持久化。

3. **播放体验**
   - 播放速度（0.5x–2x）。
   - 记忆音量、窗口位置/大小、上次播放位置。
   - 快捷键：播放/暂停、seek、音量、全屏、SR 开关等。
   - 小窗/全屏控制条不互相回归。

4. **稳定性**
   - 任务中心边播纳入长稳（至少 30–60 分钟）。
   - 本地崩溃/异常日志（D3D、cudart、TensorRT、音频设备）。
   - 诊断 JSON 继续可复制。

### P1：播放核心补强

5. **硬件解码**
   - 先做 H.264 D3D11VA/NVDEC 探测和可选解码路径。
   - 失败自动回退软件解码，诊断页显示 `inUse=true/false` 和原因。
   - 用高码率 4K/H.264、HEVC 片源验证 CPU/GPU 占用和稳定性。
   - 若 V0.3 工期不允许，明确降级到 V0.3.x，不阻塞 zip 功能完成。

6. **音频/字幕边界**
   - 无音轨/多音轨/无字幕/坏字幕不崩溃。
   - 音轨切换后 A/V 同步和 seek 不回归。

### P1：超分、模型与离线任务

7. **4K FullSource tile**
   - 降低 7680×4320 中间帧约 1.9GB 峰值。
   - tile + overlap；校验接缝/颜色一致性。
   - 目标峰值内存 <1.2GB（待实测）。

8. **模型体验**
   - HQ 模型在任务中心显示耗时/内存提示。
   - 模型清单、校验和、版本、缺失提示；本地导入优先，在线下载后置。
   - 真人 2x/3x 评估结论落文档；无合适模型则明确“真人仅 4x + 输出缩放”。

9. **任务中心**
   - 边播长稳、失败重试、续编取消/恢复回归。
   - 4K 任务完成后的文件可播放，不覆盖用户已有任务目录。

### P2：评估/后置

- HDR/色彩管理：只评估，不承诺 V0.3。
- 移动端 spike：`AudioSink` + Flutter 纹理 + NCNN Vulkan 最小闭环，不阻塞 V0.3。
- 文件关联、安装器、代码签名、自动更新：暂停，不纳入本轮功能完成标准。

## 三、推荐实施顺序

1. **绿色 zip 自包含 + 发布脚本只出 zip**（0.5–1 天）
2. **音轨/字幕 + 播放速度 + 设置/快捷键**（3–5 天）
3. **任务边播长稳 + 崩溃日志**（2–3 天）
4. **tile 4K + HQ 提示 + 模型清单/缺失提示**（1–2 周）
5. **硬件解码 H.264 可选路径**（视验证结果 3–5 天）
6. **真人 2x/3x 结论/模型管理收尾**（按模型结果）
7. **移动端 spike（可选）**

## 四、绿色包验收

- 解压到任意可写目录，双击 `domino_flutter.exe`，无需安装器/管理员。
- 缺 VC++ Runtime 时仍可运行（若随包）；否则包内说明必须明确。
- 打开 1080p/4K、切 SR、切音轨、切字幕、seek、全屏、退出均正常。
- 任务中心新建 → 编码 → 边播 → 停止/续编/删除均正常。
- 诊断页显示版本、模型路径、backend、零拷贝/回退原因。
- 1 小时 4K 播放 + 任务边播无崩溃，内存/句柄无持续增长。
- 不要求笔记本性能矩阵；但至少当前开发机 + 一台干净 Windows 可解压启动。

## 五、明确不在 V0.3 范围内

- Windows 安装器、VC++ 安装器检测、代码签名、SmartScreen 签名信誉。
- 混合显卡/核显默认 adapter 的性能矩阵。
- 文件关联、自动更新、在线模型商店/账号/遥测。
- 4K 60 / 8K / 完整移动端。
- TensorRT 可选组件拆包（保持完整 zip，后续再拆）。
